# DSA-MIRAI-JUJ-Sem1

C++ course material — theory + classwork/homework code, organized by topic:

- `01_Getting_Started_with_Cpp`
- `02_Operators`
- `03_If_Else`
- `04_Switch_Case`
- `05_Loops`
- `06_Patterns`

Each topic folder has a content PDF (theory + solved problems) and a `Codes/` folder with the matching `.cpp` files.
